Project Status Today
====================
Stock Research Agent is now running locally with a working frontend dashboard and a live FastAPI backend for the main research pages.

What has been added
-------------------
- A FastAPI backend entrypoint in main.py with endpoints for:
  - /health
  - /api/v1/stocks
  - /api/v1/dashboard
  - /api/v1/screeners
  - /api/v1/portfolios
  - /api/v1/rules
  - /api/v1/backtesting
  - /api/v1/jobs

- Frontend dashboard pages now display populated data instead of empty placeholder content.
- Added Swagger UI support for API testing at http://localhost:8000/docs.
- Added a frontend README with run instructions.
- Added a frontend .env file to point the app at the local backend and disable mocks.
- Added frontend API adapters for backtesting and jobs data.

Files added or changed
----------------------
- main.py
- frontend/README.md
- frontend/.env
- frontend/src/api/backtestingApi.ts
- frontend/src/api/jobsApi.ts

Why these changes were made
---------------------------
- To replace mock-only or placeholder UI behavior with real, data-driven pages.
- To make the dashboard and related pages functional in a local development environment.
- To support API testing and frontend-backend integration.

What the UI currently displays
------------------------------
- Dashboard: KPI cards, momentum stocks, buy signals, recent jobs, portfolio summary
- Stocks: stock table with symbol, company, sector, price, momentum, and RSI
- Screeners: screener cards with candidate counts and status
- Portfolio: portfolio summary table with value and return
- Rules: rules table with weights and active status
- Backtesting: strategy summary, equity curve, and benchmark tables
- Jobs: pipeline activity list with timestamps and statuses
